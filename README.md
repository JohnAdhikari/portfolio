# 🚀 john.space — Space Themed Portfolio

A fun, space-themed portfolio for **John Adhikari** — a self-taught full-stack developer & AI enthusiast. Explore the cosmos of my work: web apps, AI agents, and a Flutter mobile app.

## ✨ Features

- **🌌 Live starfield** — canvas stars that twinkle and drift, with occasional **shooting stars**
- **🪐 Floating planets** — a ringed Saturn, cyan Earth, and purple moon with glowing nebula clouds
- **🖱️ Mouse tracer** — custom glowing cursor + comet-style stardust trail (auto-disables on touch devices)
- **⌨️ Typewriter hero** — animated roles (Full-Stack Developer, AI Agent Builder, …)
- **🏅 Off-Duty Interests** — sports (basketball 🏀, football ⚽) and movie favorites (Harry Potter, Interstellar, Breaking Bad, The Conjuring)
- **🗂️ Sections** — About · Skills · Projects · Interests · Contact
- **🌗 Day / Night toggle** — a "sunrise" palette for light mode
- **📱 Fully responsive** — optimized for desktop, tablet and mobile
- **♿ Accessible** — respects `prefers-reduced-motion`, keyboard friendly

## 🧰 Tech Stack

| Layer | Choice |
|---|---|
| Framework | React 19, Vite 7 |
| Styling | Tailwind CSS v4 |
| Icons | react-icons (Font Awesome) |
| Fonts | Orbitron (display) + Inter (body) |
| Hosting | GitHub Pages (gh-pages) |

## 🚀 Getting Started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run deploy   # build + publish to GitHub Pages
```
