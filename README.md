# ✏️ john.space — Portfolio

A hand-drawn, anti-polish portfolio for **John Adhikari** — a self-taught full-stack developer & AI agent builder. Paper textures, pencil strokes, and a human touch instead of another template.

## ✨ Features

- **🎨 Raw / anti-polish theme** — paper grain background, dashed borders, kraft-brown + pencil palette, Caveat script headings
- **⌨️ Typewriter hero** — animated roles (Full-Stack Developer, AI Agent Builder, …) with magnetic CTAs
- **🎬 Movie & series favorites** — real poster thumbnails (Harry Potter, Interstellar, Breaking Bad, From, The Conjuring)
- **📊 Animated skills** — GSAP-driven proficiency bars that fill on scroll
- **🧭 Sections** — About · Skills · Projects · Interests · Badges · Contact
- **🌗 Light / Dark toggle** — dark paper palette with persisted preference
- **✨ GSAP motion** — scroll reveals, count-up stats, 3D portrait tilt, scroll progress bar, custom cursor (fine-pointer only)
- **📱 Fully responsive** — optimized for desktop, tablet and mobile
- **♿ Accessible** — respects `prefers-reduced-motion`, keyboard friendly, semantic markup

## 🧰 Tech Stack

| Layer | Choice |
|---|---|
| Framework | React 19, Vite 7 |
| Styling | Tailwind CSS v4 (CSS-variable design tokens) |
| Animation | GSAP + ScrollTrigger |
| Icons | react-icons (Feather / Font Awesome) |
| Fonts | Caveat (display) + Inter (body) + JetBrains Mono |
| Hosting | GitHub Pages (gh-pages) |

## 🚀 Getting Started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run deploy   # build + publish to GitHub Pages
```
